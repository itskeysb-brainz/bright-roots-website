BRIGHT ROOTS DAYCARE & KINDERGARTEN - static website (redesign, Nov 2026)

Open index.html in a browser (or upload the folder to any static host).

FILES
- assets/css/site.css : main stylesheet (blue / yellow / red, Poppins font)
- assets/css/legacy.css: header + hamburger menu, programme cards, vision & mission and video tour, kept as in the previous version
- assets/js/site.js   : all animation + behaviour (menu, hero slider, reveals, counters,
                        reviews slider, gallery filters + lightbox, forms, page transitions)
- assets/img/         : photos (every photo is used somewhere on the site)
- assets/video/tour.mp4, assets/docs/bright-roots-fees-2027.pdf

EDIT IN ONE PLACE
- Facebook / Instagram links and the WhatsApp number: the  window.BR = {...}  block at the
  bottom of each page.
- Parent reviews: index.html, section id="reviews" (names are placeholders "Parent name";
  replace with real parents, with their permission, and swap assets/img/parents/p1-p6.svg).
- Upcoming events dates: index.html section id="news" and news.html.

ANIMATIONS INCLUDED
Sticky transparent-to-blue header, hamburger drawer, hero slider with zoom and changing words,
floating shapes, magnetic buttons, scroll reveals, split-word titles, count-up numbers,
3D tilt cards, running photo columns, review slider (drag + autoplay), timeline that draws
itself, FAQ, gallery filters and lightbox, curtain page transitions, scroll progress bar.
Motion is switched off for visitors who prefer reduced motion.
